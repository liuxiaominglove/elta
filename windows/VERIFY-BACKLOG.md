## V1 深色主题渲染 🟡
- **背景**：结果窗/设置窗读 `AppsUseLightTheme`；代码路径就绪，但**仅浅色实测**（NOTES:308）。
- **步骤**：系统 → 个性化 → 颜色 → 选**深色** → 触发划词翻译一次 + 打开设置窗（`--settings-ui`）。
- **期望**：结果窗 / 设置窗按深色渲染、文字可读、无白底闪烁。
- **类型**：【需人工】——需改系统主题（可脚本改注册表 `AppsUseLightTheme`，若可自动化则升级为【自动可验】）。
- **测毕**：切回浅色（并记录已还原）。

## V2 WebView2 缺失弹窗路径 🟡
- **背景**：`WebView2FallbackLogic` 已 TDD（7 测试）；**缺 Runtime 时的弹窗壳未真机验证**（NOTES:407-411）。
- **步骤**：在**未装 WebView2 Runtime** 的环境（干净机 / 卸载 / 隔离）启动结果窗。
- **期望**：弹出友好提示 + 官方 Evergreen 下载链接；日志含 `result window fallback missingRuntime=...`。
- **类型**：【需人工】——本机已装 WebView2 v154，需专门环境（无法在已装机器复现）。

## V3 完成通知点击激活结果窗 🟡
- **背景**：翻译成功发托盘气泡「翻译完成，点击查看结果」（可见 🟢）；**点击 → 激活结果窗**未自动化（NOTES:328）。
- **步骤**：翻译一次 → 鼠标点击托盘气泡。
- **期望**：结果窗被激活到前台（`Show`/激活日志或窗口可见性断言）。
- **类型**：【自动可验】——气泡点击可用 UIA / `mouse_event` 注入（如不可则降级手动点一次）。

## V4 Word 取词
- **背景**：本机 Office 试用期届满（reduced functionality）→ SKIP（NOTES:117）。
- **步骤**：在**授权 Office** 的机器，Word 选中英文 → `Ctrl+Shift+T`。
- **期望**：取到文本（UIA 或 Ctrl+C 路径均可；日志 `selection via ...`），原剪贴板保留。
- **类型**：【需人工】——需授权 Office 环境。

## V5 真实 `Ctrl+Shift+T` 热键入口自动化
- **背景**：`test-clipboard.ps1`/`test-p1.ps1` 用 CLI 绕过热键入口；真实热键未自动化（NOTES:209/225）。
- **手段**：`keybd_event` 注入 `Ctrl+Shift+T`（AGENTS 能力清单已验证可触发 `RegisterHotKey`，勿用 SendKeys）。
- **期望**：走完整取词链路（日志出现热键触发的取词路径）。
- **类型**：【自动可验】。

## V6 Chrome/Edge（UIA 失败→Ctrl+C 兜底）路径自动化
- **背景**：Chrome/Edge 走 UIA 或 Ctrl+C 分支未自动化（NOTES:209/225）。
- **步骤**：Chrome/Edge 选中文本 → 触发取词；并构造 UIA 失败场景验证回退 Ctrl+C。
- **期望**：兜底路径取到文本 + **原剪贴板保留**；必要时可用 `--selection-cli` 辅助（注意：会合成全局 `Ctrl+C`，

- **类型**：【自动可验】（Chrome 需额外 UIA/注入自动化）。
