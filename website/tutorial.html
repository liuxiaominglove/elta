使用教程

本教程按「场景」组织，告诉你遇到某种阅读情况时该怎么做。功能参数的完整说明请查看 使用文档。

快速上手（3 分钟）

  1. 下载安装：前往 下载页面，下载 DMG 后把 ELTA.app 拖入「应用程序」，双击打开。
  2. 配置 API Key：点菜单栏 📖 图标 → 偏好设置 → API Key 标签页，填入你的 AI 服务商 Key（推荐 DeepSeek），选择对应服务商。
  3. 完成第一次翻译：打开任意英文页面，按 ⌃T 框选一段英文，松开鼠标，几秒后浮动面板就会显示翻译结果。
第一次使用会自动弹出两个系统权限请求（屏幕录制、辅助功能），按提示允许即可。详见 权限说明。

场景一：精读英文论文 PDF

读学术论文时，不仅要看译文，还想顺便记下术语和固定表达。用 ELTA 的「精读翻译」模板最合适。

  1. 用任意 PDF 阅读器（Preview、Acrobat 等）打开论文。
  2. 按下 ⌃T，拖拽框选一段英文正文。
  3. ELTA 自动截图 → 本地 OCR → AI 翻译，结果会按「中文翻译 / 重要词汇 / 常用短语与习语」结构化输出。
  4. 重点看「重要词汇」部分——它会列出句中较关键的单词（词性 + 释义），自动跳过高中基础词汇，专攻学术难点。
小技巧：PDF 里的文字不可选中，所以这里必须用「截图翻译」而不是「划词翻译」。截图翻译走本地 OCR，离线即可识别，隐私安全。

场景二：读双栏英文电子书 / 文献

双栏排版的电子书或论文，左右两页并排，普通翻译工具容易把两栏文字混在一起。用「悬停翻译」能自动只取你鼠标所在的那一栏。

  1. 把鼠标移到目标段落右下角（无需点击、无需选中文字）。
  2. 按下 ⌥⌘T。
  3. ELTA 自动识别鼠标上方半屏内容并翻译。
  4. 默认「双栏」模式会只取鼠标左侧半屏宽，正好避开另一栏；若是全屏单栏排版，可在偏好设置 → 快捷键里把「内容范围」改为「整栏」。
适用场景：带目录/侧边栏的网页、双栏 PDF、左右分页的阅读器。悬停翻译能自动绕开目录栏，只翻译正文。

场景三：浏览英文网页 / 新闻

网页和文档里的文字是可以选中的，这时用「划词翻译」最快——跳过截图和 OCR，直接翻译选中文字。

  1. 在网页里选中想翻译的英文句子或段落。
  2. 按下 ⇧⌃T（Ctrl+Shift+T）。
  3. ELTA 直接获取选中文字并调用 AI 翻译，结果立刻显示。
对比：能选中文字就用「划词翻译」（快）；文字是图片/不可选中时才用「截图翻译」（走 OCR）。

场景四：图片 / 视频字幕里的文字

截图、漫画、海报、视频字幕里的英文无法被选中，只能用「截图翻译」靠 OCR 提取。

  1. 按下 ⌃T。
  2. 框选图片或视频里包含英文的区域。
  3. ELTA 本地 OCR 识别出文字，再交给 AI 翻译。
注意：OCR 识别的是「框选区域内的清晰文字」，框选太小或文字太模糊会影响识别率，建议框选范围稍大于文字区域。

场景五：积累词汇与短语

ELTA 内置的「精读翻译」模板除了译文，还会输出「重要词汇」和「常用短语与习语」两栏，适合一边读一边做笔记。

  1. 用截图或划词翻译一段英文。
  2. 在结果面板里查看「重要词汇」（词性 + 释义）和「常用短语与习语」。
  3. 想换风格，可在偏好设置 → 模板里自定义提示词，比如改成「文学翻译」或「新闻翻译」风格。
进阶：模板支持占位符 {text}，你可以自由定制输出结构，详见 翻译模板。

进阶技巧

自定义快捷键

默认快捷键 ⌃T 可能与浏览器冲突（Chrome 新建标签页）。在偏好设置 → 快捷键里点击对应输入框，按下新组合即可替换。

多显示器切换弹窗

翻译弹窗默认出现在鼠标所在屏幕。若弹窗跑到另一块屏，按 ` 一键切回当前屏幕。

表格翻译

悬停翻译会自动识别窗口内的表格，转为 Markdown 表格交给 AI 逐格翻译，保持表格结构不变，适合阅读带数据表的英文资料。

重复翻译对比结果

对同一区域再次按 ⌃T，可以用相同内容重复翻译，方便对比不同 AI 后端或模板的输出差异。
