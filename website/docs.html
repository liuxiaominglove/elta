使用文档

ELTA 是一款专为英语精读设计的 macOS 截图/划词/悬停翻译工具。还没安装？请先看 安装教程。

使用方式

截图翻译

  1. 在任意页面（浏览器、PDF 阅读器、电子书等）找到需要翻译的英文
  2. 按下快捷键 ⌃T
  3. 鼠标变为十字准星，拖拽框选英文文本区域
  4. 松开鼠标后，ELTA 自动：
    • 截取框选区域的图像
    • 调用本地 OCR 识别英文文字
    • 发送给 AI 后端翻译
    • 在浮动面板显示翻译结果
  5. 拖动浮动面板可以调整位置，缩放可以调整大小

划词翻译

  1. 在任意应用中选中英文文本
  2. 按下快捷键 ⇧⌃T（Ctrl+Shift+T）
  3. ELTA 自动获取选中文字 → 直接 AI 翻译（跳过截图+OCR，速度更快）

💡 对比：截图翻译适合图片/PDF 中的不可选文字；划词翻译适合网页/文档中可选中的文字。

悬停翻译（免截图/划词）

  1. 将鼠标移到目标段落的右下角（无需点击、无需选中文字）
  2. 按下快捷键 ⌥⌘T（Option+Cmd+T）
  3. ELTA 自动识别鼠标上方约半屏内容并翻译；可在 偏好设置 → 快捷键 选择「内容范围」：双栏（左右分页，取鼠标左侧半屏宽）或 整栏（全屏单栏，取整屏宽）
  4. 窗口内的表格会自动转为 Markdown 表格，AI 逐格翻译、保持表格结构

💡 适用场景：阅读双栏电子书、带目录/侧栏的网页时，悬停翻译能自动避开目录栏与浏览器 chrome，只翻译正文。

重复翻译

再次按下 ⌃T 可以使用相同区域重复翻译（适合对比不同翻译结果）。

使用场景

场景一：精读英文论文 PDF

读学术论文时，不仅要译文，还想顺便记下术语和固定表达，用「精读翻译」模板最合适。

  1. 用任意 PDF 阅读器（Preview、Acrobat 等）打开论文。
  2. 按下 ⌃T，拖拽框选一段英文正文。
  3. ELTA 自动截图 → 本地 OCR → AI 翻译，结果按「中文翻译 / 重要词汇 / 常用短语与习语」结构化输出。
  4. 重点看「重要词汇」——列出句中较关键的单词（词性 + 释义），自动跳过高中基础词汇，专攻学术难点。
小技巧：PDF 里的文字不可选中，必须用「截图翻译」而非「划词翻译」。截图翻译走本地 OCR，离线即可识别，隐私安全。

场景二：读双栏英文电子书 / 文献

双栏排版的电子书或论文，左右两页并排，普通工具容易把两栏文字混在一起。用「悬停翻译」能自动只取鼠标所在的那一栏。

  1. 把鼠标移到目标段落右下角（无需点击、无需选中文字）。
  2. 按下 ⌥⌘T。
  3. ELTA 自动识别鼠标上方半屏内容并翻译。
  4. 默认「双栏」模式只取鼠标左侧半屏宽，正好避开另一栏；若是全屏单栏排版，可在偏好设置 → 快捷键里把「内容范围」改为「整栏」。
适用场景：带目录/侧边栏的网页、双栏 PDF、左右分页的阅读器。悬停翻译能自动绕开目录栏，只翻译正文。

场景三：浏览英文网页 / 新闻

网页和文档里的文字可以选中，这时用「划词翻译」最快——跳过截图和 OCR，直接翻译选中文字。

  1. 在网页里选中想翻译的英文句子或段落。
  2. 按下 ⇧⌃T（Ctrl+Shift+T）。
  3. ELTA 直接获取选中文字并调用 AI 翻译，结果立刻显示。
对比：能选中文字就用「划词翻译」（快）；文字是图片/不可选中时才用「截图翻译」（走 OCR）。

场景四：图片 / 视频字幕里的文字

截图、漫画、海报、视频字幕里的英文无法被选中，只能用「截图翻译」靠 OCR 提取。

  1. 按下 ⌃T。
  2. 框选图片或视频里包含英文的区域。
  3. ELTA 本地 OCR 识别出文字，再交给 AI 翻译。
注意：OCR 识别的是「框选区域内的清晰文字」，框选太小或文字太模糊会影响识别率，建议框选范围稍大于文字区域。

场景五：积累词汇与短语

内置的「精读翻译」模板除了译文，还会输出「重要词汇」和「常用短语与习语」两栏，适合一边读一边做笔记。

  1. 用截图或划词翻译一段英文。
  2. 在结果面板查看「重要词汇」（词性 + 释义）和「常用短语与习语」。
  3. 想换风格，可在偏好设置 → 模板里自定义提示词，比如改成「文学翻译」或「新闻翻译」风格。
进阶：模板支持占位符 {text}，可自由定制输出结构，详见下方翻译模板。

快捷键

快捷键功能说明
⌃T（可自定义）截图翻译全局可用，框选屏幕区域 → 自动 OCR + 翻译
⇧⌃T（可自定义）划词翻译选中文本后使用，跳过 OCR 直接翻译
⌥⌘T（可自定义）悬停翻译鼠标移到段落右下角，自动识别该段并翻译（免截图/划词）
`（可自定义）切换弹窗位置翻译弹窗可见时，一键切换弹窗到屏幕另一侧
Esc（可自定义）关闭关闭翻译结果浮动面板，可在偏好设置中修改

你可以在 偏好设置 → 快捷键 中自定义截图、划词、悬停、切换弹窗以及关闭面板的快捷键。

翻译模板

ELTA 支持自定义翻译模板，在 偏好设置 → 模板 中编辑。你可以使用以下占位符：

  • {text} — 待翻译的英文原文

内置模板

模板名称：精读翻译 
我会给你一段英文文本。请你按以下结构输出：

原文：
{text}

## 中文翻译
（遵循"信达雅"原则，自然流畅的中文翻译）

## 重要词汇
- **单词** | 词性 | 中文释义
（列出句中较重要的词汇，跳过高中大纲基础词汇）

## 常用短语与习语
- 短语/习语：中文释义
（习语请标注【习语】）

你可以在偏好设置中添加、编辑或删除自定义模板。

常见问题

Q: OCR 识别不出文字？

  • 确保框选区域包含清晰的英文文本
  • 避免框选过小（建议至少 50×20 像素）
  • 确保你的 macOS 版本 ≥ 13.0（Vision OCR 需要 Ventura 以上）

Q: 翻译失败或报错？

  • 检查偏好设置中的 API Key 是否正确填入
  • 检查选中的 AI 服务商是否与 API Key 匹配
  • 确认网络连接正常（OCR 是离线的，但翻译需要联网）
  • 查看 API 账户是否有可用额度

Q: 快捷键与其他 App 冲突怎么办？

默认截图翻译快捷键 ⌃T 可能与浏览器（Chrome 新标签页）或其他工具冲突。在 ELTA 偏好设置 → 快捷键 中，点击对应输入框，按下新的快捷键组合即可替换（例如改为 ⌥⌃T）。

Q: 支持自定义 API 端点吗？

支持。在 偏好设置 → API Key 中，如果你使用 OpenAI 兼容的中转接口或私有部署，可以修改自定义 base URL（如 https://api.your-server.com/v1），同时填入对应的 API Key 和选择 provider 为 OpenAI 即可。

Q: API Key 存储安全吗？

安全。API Key 存储在 macOS 系统 Keychain 中，不会以明文形式写入任何文件。其他应用无法读取 ELTA 保存的 Key。

Q: 翻译结果格式异常怎么办？

  • 确认 偏好设置 → API Key 中选择了正确的 AI 后端（DeepSeek / OpenAI / Gemini）
  • 如果你使用自定义 base URL，确保目标模型支持 chat 格式（某些纯 completion 模型不遵循结构化输出指令）
  • 可在偏好设置中尝试切换到另一个 provider 测试是否恢复正常

Q: 多显示器/外接屏幕弹窗不显示？

翻译弹窗默认在鼠标当前所在的屏幕上出现。若弹窗跑到另一块屏幕，按下 `（可自定义）即可切换到当前屏幕。
