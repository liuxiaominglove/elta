使用文档

ELTA 是一款专为英语精读设计的 macOS 截图翻译工具。以下文档帮助你快速上手。

安装说明

方式一：手动安装（推荐）

  1. 从下载页面获取 ELTA(v5.1).dmg
  2. 双击打开 DMG，将 ELTA.app 拖入 Applications 文件夹
  3. 首次打开时，可能提示"无法验证"。macOS 14 及以下：右键点击 ELTA.app → "打开"
  4. macOS 15 (Sequoia) 及以上：打开终端，输入以下命令后回车： 
    xattr -cr /Applications/ELTA.app
    然后再双击 ELTA 即可正常打开。
  5. 如若仍然无法打开，请查看页面底部常见问题。
系统要求：macOS 13.0 (Ventura) 或更高版本，支持 Intel 和 Apple Silicon（M 系列）芯片。

初始设置

  1. 启动 ELTA 后，点击菜单栏的 📖 图标
  2. 选择 "偏好设置"
  3. 在 API Key 标签页中，填入你选择的 AI 服务商的 API Key（优先推荐 DeepSeek 服务商）：
    • DeepSeek：前往 platform.deepseek.com 获取
    • OpenAI：前往 platform.openai.com 获取
    • Google Gemini：前往 aistudio.google.com 获取
  4. 选择对应的服务商（Provider）
  5. 关闭偏好设置窗口，即可开始使用

使用方式

截图翻译

  1. 在任意页面（浏览器、PDF 阅读器、电子书等）找到需要翻译的英文
  2. 按下快捷键 Cmd+T
  3. 鼠标变为十字准星，拖拽框选英文文本区域
  4. 松开鼠标后，ELTA 自动：
    • 截取框选区域的图像
    • 调用本地 OCR 识别英文文字
    • 发送给 AI 后端翻译
    • 在浮动面板显示翻译结果
  5. 拖动浮动面板可以调整位置，缩放可以调整大小

划词翻译（新增！）

  1. 在任意应用中选中英文文本
  2. 按下快捷键 ⇧⌘T（Shift+Cmd+T）
  3. ELTA 自动获取选中文字 → 直接 AI 翻译（跳过截图+OCR，速度更快）

💡 对比：截图翻译适合图片/PDF 中的不可选文字；划词翻译适合网页/文档中可选中的文字。

重复翻译

再次按下 Cmd+T 可以使用相同区域重复翻译（适合对比不同翻译结果）。

快捷键

快捷键功能说明
Cmd+T截图翻译全局可用，框选屏幕区域 → 自动 OCR + 翻译
⇧⌘T划词翻译选中文本后使用，跳过 OCR 直接翻译

你可以在 偏好设置 → 快捷键 中自定义截图和划词的快捷键。

翻译模板

ELTA 支持自定义翻译模板，在 偏好设置 → 模板 中编辑。你可以使用以下占位符：

  • {text} — 待翻译的英文原文

内置模板

模板名称：精读翻译

（遵循"信达雅"原则，自然流畅的中文翻译）

（习语请标注【习语】）

常见问题

Q: 打开 App 时提示"无法验证开发者"？

因为 ELTA 未加入 Apple 开发者计划。系统可能会提示：
"Apple无法验证"ELTA"是否包含可能危害Mac安全或泄漏隐私的恶意软件。"
请前往 系统设置 → 隐私与安全性，在页面最底部找到 ELTA 的提示，例如："已阻止 'ELTA' 保护 Mac"，点击 "仍要打开"。

Q: OCR 识别不出文字？

  • 确保框选区域包含清晰的英文文本
  • 避免框选过小（建议至少 50×20 像素）
  • 确保你的 macOS 版本 ≥ 13.0（Vision OCR 需要 Ventura 以上）

Q: 翻译失败或报错？

  • 检查偏好设置中的 API Key 是否正确填入
  • 检查选中的 AI 服务商是否与 API Key 匹配
  • 确认网络连接正常（OCR 是离线的，但翻译需要联网）
  • 查看 API 账户是否有可用额度

Q: 支持 Windows 或 Linux 吗？

目前 ELTA 仅支持 macOS。核心功能依赖 Apple 的 Vision 框架和 Cocoa/AppKit，暂无跨平台计划。
