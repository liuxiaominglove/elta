使用文档

ELTA 是一款专为英语精读设计的 macOS 截图/划词/悬停翻译工具。以下文档帮助你快速上手。

安装说明

手动安装

  1. 前往 下载页面，按提示下载最新版 ELTA.dmg
  2. 双击打开 DMG，将 ELTA.app 拖入 Applications 文件夹
  3. 首次打开时，可能提示"无法验证"，可通过以下任一方式解决：
    • 方式一（终端）：打开终端，输入以下命令后回车，再双击 ELTA 即可正常打开： 
      xattr -cr /Applications/ELTA.app
    • 方式二（系统设置）：前往 系统设置 → 隐私与安全性，在页面最底部找到 ELTA 的提示（"已阻止 'ELTA' 保护 Mac"），点击 "仍要打开"。
  4. 如若仍然无法打开，请查看页面底部常见问题。
系统要求：macOS 13.0 (Ventura) 或更高版本，支持 Intel 和 Apple Silicon（M 系列）芯片。

更新版本

  1. 前往 下载页面，按提示下载最新版 DMG
  2. 双击打开，将新的 ELTA.app 拖入 Applications，选择"替换"即可
  3. 偏好设置、快捷键与 API Key 配置会自动保留，无需重新设置

卸载方法

  1. 将 /Applications/ELTA.app 拖入废纸篓，或右键 → 移到废纸篓
  2. 如需彻底清理配置文件，手动删除 ~/Library/Preferences/com.elta.app.plist 文件（可选）

初始设置

  1. 启动 ELTA 后，点击菜单栏的 📖 图标
  2. 选择 "偏好设置"
  3. 在 API Key 标签页中，填入你选择的 AI 服务商的 API Key（优先推荐 DeepSeek 服务商）：
    • DeepSeek：前往 platform.deepseek.com 获取
    • OpenAI：前往 platform.openai.com 获取
    • Google Gemini：前往 aistudio.google.com 获取
    • Anthropic：前往 console.anthropic.com 获取
  4. 选择对应的服务商（Provider）
  5. 关闭偏好设置窗口，即可开始使用

使用方式

截图翻译

  1. 在任意页面（浏览器、PDF 阅读器、电子书等）找到需要翻译的英文
  2. 按下快捷键 ⌃T
  3. 鼠标变为十字准星，拖拽框选英文文本区域
  4. 松开鼠标后，ELTA 自动：
    • 截取框选区域的图像
    • 调用本地 OCR 识别英文文字
    • 发送给 AI 后端翻译
    • 在浮动面板显示翻译结果
  5. 拖动浮动面板可以调整位置，缩放可以调整大小

划词翻译

  1. 在任意应用中选中英文文本
  2. 按下快捷键 ⇧⌃T（Ctrl+Shift+T）
  3. ELTA 自动获取选中文字 → 直接 AI 翻译（跳过截图+OCR，速度更快）

💡 对比：截图翻译适合图片/PDF 中的不可选文字；划词翻译适合网页/文档中可选中的文字。

悬停翻译（免截图/划词）

  1. 将鼠标移到目标段落的右下角（无需点击、无需选中文字）
  2. 按下快捷键 ⌥⌘T（Option+Cmd+T）
  3. ELTA 自动识别鼠标上方约半屏内容并翻译；可在 偏好设置 → 快捷键 选择「内容范围」：双栏（左右分页，取鼠标左侧半屏宽）或 整栏（全屏单栏，取整屏宽）
  4. 窗口内的表格会自动转为 Markdown 表格，AI 逐格翻译、保持表格结构

💡 适用场景：阅读双栏电子书、带目录/侧栏的网页时，悬停翻译能自动避开目录栏与浏览器 chrome，只翻译正文。

重复翻译

再次按下 ⌃T 可以使用相同区域重复翻译（适合对比不同翻译结果）。

快捷键

快捷键功能说明
⌃T（可自定义）截图翻译全局可用，框选屏幕区域 → 自动 OCR + 翻译
⇧⌃T（可自定义）划词翻译选中文本后使用，跳过 OCR 直接翻译
⌥⌘T（可自定义）悬停翻译鼠标移到段落右下角，自动识别该段并翻译（免截图/划词）
`（可自定义）切换弹窗位置翻译弹窗可见时，一键切换弹窗到屏幕另一侧
Esc（可自定义）关闭关闭翻译结果浮动面板，可在偏好设置中修改

你可以在 偏好设置 → 快捷键 中自定义截图、划词、悬停、切换弹窗以及关闭面板的快捷键。

翻译模板

ELTA 支持自定义翻译模板，在 偏好设置 → 模板 中编辑。你可以使用以下占位符：

  • {text} — 待翻译的英文原文

内置模板

模板名称：精读翻译 
我会给你一段英文文本。请你按以下结构输出：

原文：
{text}

## 中文翻译
（遵循"信达雅"原则，自然流畅的中文翻译）

## 重要词汇
- **单词** | 词性 | 中文释义
（列出句中较重要的词汇，跳过高中大纲基础词汇）

## 常用短语与习语
- 短语/习语：中文释义
（习语请标注【习语】）

你可以在偏好设置中添加、编辑或删除自定义模板。

权限说明

ELTA 使用翻译功能时，需要两项 macOS 系统权限。首次按下 ⌃T（截图翻译）或 ⇧⌃T（划词翻译）时，系统会自动依次弹出授权提示。

需要哪些权限？为什么？

权限用途设置路径
屏幕录制 截图翻译功能需要截取屏幕画面进行 OCR 识别 系统设置 → 隐私与安全性 → 屏幕录制
辅助功能 划词翻译功能需要读取你在其他 App 中选中的文本 系统设置 → 隐私与安全性 → 辅助功能
关于音频提示：屏幕录制权限的系统提示中会包含"录制屏幕和音频"字样，这是 Apple 的固定文案，ELTA 不会录制任何音频，仅用于屏幕截图。

常见问题

Q: 打开 App 时提示"无法验证开发者"？

因为 ELTA 未加入 Apple 开发者计划。系统可能会提示：
"Apple无法验证"ELTA"是否包含可能危害Mac安全或泄漏隐私的恶意软件。"
请前往 系统设置 → 隐私与安全性，在页面最底部找到 ELTA 的提示，例如："已阻止 'ELTA' 保护 Mac"，点击 "仍要打开"。

Q: OCR 识别不出文字？

  • 确保框选区域包含清晰的英文文本
  • 避免框选过小（建议至少 50×20 像素）
  • 确保你的 macOS 版本 ≥ 13.0（Vision OCR 需要 Ventura 以上）

Q: 翻译失败或报错？

  • 检查偏好设置中的 API Key 是否正确填入
  • 检查选中的 AI 服务商是否与 API Key 匹配
  • 确认网络连接正常（OCR 是离线的，但翻译需要联网）
  • 查看 API 账户是否有可用额度

Q: 支持 Windows 或 Linux 吗？

目前 ELTA 仅支持 macOS。核心功能依赖 Apple 的 Vision 框架和 Cocoa/AppKit，暂无跨平台计划。

Q: 授权后仍提示无权限怎么办？

  1. 完全退出 ELTA（菜单栏图标 → 退出）
  2. 打开系统设置 → 隐私与安全性
  3. 进入「辅助功能」和「屏幕录制」页面
  4. 分别选中列表中的 ELTA，点击下方 − 号删除
  5. 再点击下方 + 号，在弹出的文件选择器中找到 /Applications/ELTA.app 并添加
  6. 确保新添加的 ELTA 开关已打开
  7. 重新打开 ELTA 再试一次

Q: 快捷键与其他 App 冲突怎么办？

默认截图翻译快捷键 ⌃T 可能与浏览器（Chrome 新标签页）或其他工具冲突。在 ELTA 偏好设置 → 快捷键 中，点击对应输入框，按下新的快捷键组合即可替换（例如改为 ⌥⌃T）。

Q: 支持自定义 API 端点吗？

支持。在 偏好设置 → API Key 中，如果你使用 OpenAI 兼容的中转接口或私有部署，可以修改自定义 base URL（如 https://api.your-server.com/v1），同时填入对应的 API Key 和选择 provider 为 OpenAI 即可。

Q: API Key 存储安全吗？

安全。API Key 存储在 macOS 系统 Keychain 中，不会以明文形式写入任何文件。其他应用无法读取 ELTA 保存的 Key。

Q: 翻译结果格式异常怎么办？

  • 确认 偏好设置 → API Key 中选择了正确的 AI 后端（DeepSeek / OpenAI / Gemini）
  • 如果你使用自定义 base URL，确保目标模型支持 chat 格式（某些纯 completion 模型不遵循结构化输出指令）
  • 可在偏好设置中尝试切换到另一个 provider 测试是否恢复正常

Q: 多显示器/外接屏幕弹窗不显示？

翻译弹窗默认在鼠标当前所在的屏幕上出现。若弹窗跑到另一块屏幕，按下 `（可自定义）即可切换到当前屏幕。
