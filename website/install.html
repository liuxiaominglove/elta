安装教程

从下载到第一次翻译，5 分钟装好 ELTA。安装完成后，各功能的具体用法请查看 使用文档。

下载

国内直链下载（推荐） GitHub 下载（海外备用）

国内用户请用直链；GitHub 打不开属网络正常现象，无需代理。若 GitHub Assets 区域被折叠，点 Assets ▼ 展开，只下载 .dmg 结尾的安装包。

安装

  1. 双击打开下载的 .dmg 文件
  2. 把 ELTA.app 拖入 Applications（应用程序） 文件夹
  3. 在启动台或「应用程序」中双击 ELTA 即可打开（应用已通过 Apple 公证，不会出现「无法验证」安全弹窗）
系统要求：macOS 13.0 (Ventura) 或更高版本，支持 Intel 和 Apple Silicon（M 系列）芯片，体积仅 4MB。

更新版本

  1. 重新下载最新版 DMG
  2. 双击打开，将新的 ELTA.app 拖入 Applications，选择「替换」即可
  3. 偏好设置、快捷键与 API Key 配置会自动保留，无需重新设置

卸载方法

  1. 将 /Applications/ELTA.app 拖入废纸篓，或右键 → 移到废纸篓
  2. 如需彻底清理配置，手动删除 ~/Library/Preferences/com.elta.app.plist（可选）

首次授权

首次按下 ⌃T（截图翻译）或 ⇧⌃T（划词翻译）时，系统会自动依次弹出两项授权提示，按提示允许即可。

需要哪些权限？为什么？

权限用途设置路径
屏幕录制 截图翻译需要截取屏幕画面进行 OCR 识别 系统设置 → 隐私与安全性 → 屏幕录制
辅助功能 划词翻译需要读取你在其他 App 中选中的文本 系统设置 → 隐私与安全性 → 辅助功能
关于音频提示：屏幕录制权限的系统提示中会包含「录制屏幕和音频」字样，这是 Apple 的固定文案，ELTA 不会录制任何音频，仅用于屏幕截图。

配置 API Key

  1. 点击菜单栏的 📖 图标，选择 「偏好设置」
  2. 在 API Key 标签页填入你选择的 AI 服务商的 Key（优先推荐 DeepSeek）：
    • DeepSeek：platform.deepseek.com
    • 千问（阿里云）：bailian.console.aliyun.com
  3. 选择对应的服务商（Provider）
  4. 关闭偏好设置窗口，即可开始使用
费用说明：ELTA 本身完全免费，翻译功能需要你自行注册 AI 服务商的 API Key，费用由服务商收取。支持的全部服务商见 使用文档 → AI 后端。

安装常见问题

Q: 打开 App 时提示「无法验证开发者」？

从 v5.2.2 起，ELTA 已使用 Apple Developer ID 签名并通过公证（notarization），从官网或 GitHub 下载后直接双击即可打开，不会再出现「无法验证」弹窗。若你使用的是旧版本（v5.2.1 及更早），重新下载最新版即可解决。

Q: 授权后仍提示无权限怎么办？

  1. 完全退出 ELTA（菜单栏图标 → 退出）
  2. 打开系统设置 → 隐私与安全性
  3. 进入「辅助功能」和「屏幕录制」页面
  4. 分别选中列表中的 ELTA，点击下方 − 号删除
  5. 再点击下方 + 号，在弹出的文件选择器中找到 /Applications/ELTA.app 并添加
  6. 确保新添加的 ELTA 开关已打开
  7. 重新打开 ELTA 再试一次

Q: 支持 Windows 或 Linux 吗？

目前 ELTA 仅支持 macOS。核心功能依赖 Apple 的 Vision 框架和 Cocoa/AppKit，暂无跨平台计划。
