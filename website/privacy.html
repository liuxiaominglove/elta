隐私政策

ELTA（以下简称"本软件"）高度重视用户隐私。本隐私政策说明我们如何收集、使用和保护你的信息。

概述

ELTA 是一款本地运行的 macOS 桌面应用。核心翻译流程（截图、OCR 文字识别）均在你的设备上完成。我们不会收集、上传或存储你的屏幕截图、识别文本或翻译内容。

数据收集

我们不收集的数据

  • 屏幕截图 — 截图仅在本地内存中处理，OCR 完成后立即释放
  • OCR 识别文本 — 本地 Vision 引擎处理后，仅用于翻译请求，不作留存
  • 翻译结果 — 翻译结果仅在浮动面板中展示，关闭后即消失
  • 浏览历史 / 使用习惯 — 本软件不含任何埋点、分析或追踪代码
  • 个人信息 — 不收集设备 ID、Apple ID、邮件地址等任何可识别身份的信息

本地存储的信息

  • API Key — 你配置的 AI 服务商密钥，存储在 macOS Keychain（系统级加密钥匙串）中
  • 偏好设置 — 快捷键、翻译模板等配置，存储在本地 UserDefaults 中
  • 运行日志 — 应用运行日志存储在 ~/Library/Logs/elta.log，仅在你的设备上，用于排查问题

数据使用

翻译过程中，OCR 识别出的英文文本会发送到你选择的 AI 服务商（DeepSeek 或千问）进行翻译处理。这是翻译功能的必要步骤。除此之外，你的数据不会被发送到任何其他服务器。

系统权限

权限用途必要性
屏幕录制 截图翻译功能需要截取屏幕画面 仅截图翻译功能必需
辅助功能 划词翻译功能需读取你在其他应用中选中的文本 仅划词翻译功能必需
说明：屏幕录制权限的系统提示文案包含"录制屏幕和音频"，这是 Apple 的固定描述。ELTA 不会录制任何音频内容。

第三方服务

AI 翻译服务商

当你使用翻译功能时，英文原文会发送到你选择的 AI 服务商进行处理。各服务商的隐私政策请参见其官方网站：

  • DeepSeek：platform.deepseek.com/privacy
  • 千问（阿里云）：bailian.console.aliyun.com
建议：请查阅相应 AI 服务商的隐私政策，了解其如何处理你发送的文本数据。本软件不参与第三方如何将数据用于模型训练等用途的决策。

数据存储与安全

  • API Key 存储在 macOS Keychain（系统级加密存储）
  • 偏好设置 存储在本地 UserDefaults，不联网
  • 日志文件 仅在本地，不自动上传
  • 翻译过程中的数据 仅在内存中处理，不落地存储

用户权利

由于本软件几乎不在本地以外存储数据：

  • 你可以随时在偏好设置中查看、修改或删除你的 API Key 和配置
  • 你可以随时在系统设置中撤销屏幕录制和辅助功能权限

我们可能会不时更新本隐私政策。更新后的政策将发布在本页面，重大变更会通过应用更新日志或网站公告通知。
