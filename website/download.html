下载 ELTA

支持 macOS 13.0+ · Intel / Apple Silicon 通用 · 完全免费

国内直链下载（推荐） GitHub 下载（海外备用）

国内用户请用上方直链；GitHub 打不开属网络正常现象，无需代理。

1

选择下载方式

国内用户：点击上方蓝色「国内直链下载」按钮，直接从本站服务器下载。

海外用户：点击「GitHub 下载」，进入 GitHub Releases 页。

2

下载 .dmg 文件

国内直链会直接下载 latest.dmg；GitHub 则需在页面下方 Assets 区域找到带 .dmg 的文件（例如 ELTA.v5.2.2.dmg）。

小提示：如果 GitHub 打不开，是境外站点网络原因，直接用国内直链即可；若 Assets 区域被折叠，点击 Assets ▼ 展开，只点 .dmg 结尾的安装包，不要点 Source code。
3

安装并打开

下载完成后，双击 .dmg 文件，把 ELTA.app 拖到 Applications（应用程序）文件夹即可。首次打开如果遇到安全提示，请查看安装文档。
